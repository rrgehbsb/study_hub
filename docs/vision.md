# What the owner wants (in their words, condensed)

Written down on 2026-11-09 from a long voice message. Keep it as the reference for "is this what Tom asked for?".

- **A dashboard about learning.** All homework and when it's due, all tests and when they are, assignments.
- **It knows my week:** what I do and when I have free time, so it knows how much I need to learn before each test.
- **It updates itself:** tests often get updated about 2 weeks before. It should tell me: "You have a test in 5 days, you need to start now, you have time here, here and here."
- **It teaches me the topic, even from zero.** For the last test I came from zero, learned a lot and felt good, and still got lost in the test.
- **At the level of my teacher at school.** That's why recording lessons matters: the tutor teaches from what the teacher actually said. Almost a one-to-one replica, maybe better, because it has the transcripts and everything from before.
- **Good at everything:** maths, physics, all subjects.
- **Free where possible, but never at the cost of quality.** The transcript has to be good, because the tutor learns from it, not from the summary. Summaries are just for me and I'll use them less. **Teaching to the test is the main thing and it has to be perfect.** (Budget: about $10/month for the AI teacher.)
- **The board problem:** sometimes I need a picture of the board; I might miss one before it's erased. I can upload notes. Videos or pictures may matter too.
- **I have no time and no energy.** Volleyball, robotics. I come home tired. Everything must be simple and mostly automatic. I don't want to write prompts or send it info each time. It should have access to everything.
- **Sources:** Ofek (homework, some teachers post only there), Mashov (tests, teacher messages; the physics teacher sends material there), WhatsApp (teachers send class summaries). I'd rather not keep my computer on 24/7.
- **Connected to my main Dashboard.** I open the Dashboard every day; the learning dashboard only sometimes. So the Dashboard must keep me updated, and homework moves between them.
- **Later:** the main Dashboard gets a weekly planner (school, volleyball, gym, robotics, minimums for each). The learning dashboard reads my free time from it. I need the learning dashboard ASAP, so it can start without that.
